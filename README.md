# MyWebsite

Freelancer-Website von Michel Leotta. Next.js 16, Tailwind v4, shadcn/ui, Motion, MDX.

```bash
npm install
npm run dev        # http://localhost:3000, Styleguide unter /styleguide
npm run lint
npm run build
```

Design-System „Systemplan“ und Regeln für Agenten: [AGENTS.md](AGENTS.md).
Entwürfe aus Phase 1: `design/phase-1/`.
