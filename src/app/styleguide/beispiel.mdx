## Überschrift im Artikel

Fließtext im Blog ist auf **68 Zeichen** begrenzt. Links sehen [so aus](/styleguide), Inline-Code wie `pnpm dlx shadcn add` bekommt eine Papier-2-Fläche.

- Aufzählungen nutzen eckige Marker
- Kein Emoji als Icon
- Versalien nur in Labels

```ts
// Code-Blöcke aus Markdown bekommen automatisch den Kopier-Button
export const ease = "cubic-bezier(.19, 1, .22, 1)"
```

> Ein Zitat aus Markdown wird zum Zitat-Baustein.

<Callout variant="tip">MDX kann alle Bausteine direkt verwenden.</Callout>
